Материалы курса

Приём, сортировка, транскрипция и рефераты — полностью локально

Мои данные

ФИО и номер группы для титульного листа реферата и имени PDF-файла.

GigaChat API

Ключ авторизации GigaChat (developers.sber.ru/studio) — когда указан, рефераты пишет облачный GigaChat-Pro вместо локальной модели: значительно быстрее.

Указания преподавателя

Свободный текст — например, что лекция переведена в дистанционный формат, какие рефераты обязательны, как сопоставлять видео с заданиями. Передаётся GigaChat и при определении номера лекции по видео, и при написании реферата.

Папки Google Диска

Вставьте ссылку на папку, которой поделился преподаватель — доступ по ссылке, без входа и ключей.

Материалы

Отметьте несколько лекций галочками, чтобы написать один общий реферат сразу по нескольким видео.

Архив лекций

Кнопка «Следующая лекция» переносит сюда видео, расшифровки и рефераты текущей лекции (на компьютере — папка archive рядом с проектом) и очищает список. Вернуться к лекции можно в любой момент — текущая при этом сама сохранится в архив.

Проверить готовый реферат

Загрузите любой PDF (свой или сгенерированный) — сервис сверит его с требованиями из задания.
